# Student Study Planner
A simple desktop study planner built with Python and Tkinter. The application allows students to organize study tasks by course, track completed tasks, and save tasks for future sessions.

## Features

* Add study tasks
* Organize tasks by course
* View saved tasks
* Mark tasks as completed
* Remove tasks
* Save tasks to a text file
* Automatically load saved tasks when the application starts
* Simple graphical user interface

## Technologies Used
* Python
* Tkinter
* File Handling

## How to Run

1. Make sure Python 3 is installed.
2. Download or clone this repository.
3. Open the project folder in VS Code or another Python IDE.
4. Run:

```bash
python3 main.py
```

5. The Student Study Planner window will open.

## How It Works

Users select a course and enter a study task. The task is added to the task list with the selected course.

Tasks can then be completed, removed, or saved. Saved tasks are stored in a text file and automatically loaded when the application is opened again.
